03

Riot API와 데이터 저장 방식

전적 조회와 픽창 감지는 서로 다른 통로를 씁니다. API 키는 제가 임의로 발급하거나 넣을 수 없고, 사용자 Riot Developer Portal 키가 필요해요.

전적 통계

Riot API로 매치 목록과 상세 데이터를 가져온 뒤, 우리 사이트의 작은 캐시에 저장해 재계산합니다. 매번 op.gg를 긁는 방식이 아니라 공식 API를 쓰는 구성이 맞습니다.

실시간 픽창

Riot 웹 API가 아니라 PC 안의 LoL Client LCU API를 읽습니다. 브라우저가 직접 접근하기 어려워서 `lcu-proxy.js`가 중간에서 안전하게 프록시합니다.

저장소

지금 프로토타입은 브라우저 설정만 `localStorage`에 저장합니다. 실제 전적 캐시는 나중에 SQLite, Supabase, Firebase 중 하나로 붙이면 됩니다.

실행 메모 실시간 감지는 `npm start`로 열어야 작동합니다. 그냥 파일로 열면 디자인과 샘플 통계만 볼 수 있어요.
